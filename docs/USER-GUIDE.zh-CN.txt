帧剪 FrameCut 1.2.1 绿色版
======================

运行
完整解压后，双击 FrameCut.exe。保留同目录的 engine 文件夹。
适用 Windows 10 / 11 64 位，系统具有 .NET Framework 4.8。
无需安装 Python、Node.js 或 FFmpeg，无账号、无上传、无自动更新。

添加新视频到现有项目
1. 打开已有工程，或先点击“新建视频”打开第一个视频。
2. 点击“＋ 添加视频到工程”，可以一次选择多个文件。
3. 新视频接在当前成片的末尾，原有片段的裁剪与顺序保留。
4. 新视频会成为独立画面卡片。点击定位，按 S 分割，再拖动卡片调整顺序。
5. 点击“从头预览”检查拼接结果，最后导出 MP4。

直接拖入一个或多个视频也会追加到当前工程。
如果还没有工程，添加视频会直接创建一个新工程。
“新建视频”用于另开一个工程，会先提示保存当前修改。
“打开工程”用于恢复 .framecut 工程。
导入多个文件时按文件选择器返回的顺序加入，画面顺序可随后拖动调整。

画轨切割、重排
• 下方“成片编排”同时显示全部画面片段，A、B、C 等字母不会随重排改变。
• 点击画面定位，按 S 或点击“分割画轨”，在当前帧之前切开。
• 直接拖动画面卡片换位，或在左侧选中片段后点“前移 / 后移”。
• ← / → 逐帧查看；在成片模式下，跨片段时按重新排列后的顺序前进或后退。
• I / O 设置当前片段入点、出点；出点包含当前帧。
• 帧号输入框、入点、出点都使用当前视频自身的帧号，从 1 开始。
• 单个片段的裁剪范围限定在它所属的视频内，多个片段通过时间轴拼接。
• “原片定位 / 裁剪”时间轴按素材加入顺序累计显示时间，点击可定位到对应素材。
• “保存此帧”将当前源视频的原尺寸画面保存为 PNG。

原声连续与音画分离
默认勾选“只剪画轨，原声保持连续”。
重排画面卡片时，已有声音不会跟随画面重新排序。

添加新视频时，声音接在加入前的成片结尾：
例如现有成片已裁成 2.5 秒，再加入 1 秒视频，新视频的声音从成片第 2.5 秒开始。
即使原素材原本长 8 秒，也不会把未使用的尾部重新插到新视频声音之前。
新加入的视频无声时，对应位置保留静音，不把后面视频的声音提前。
之后如果继续缩短成片，原声按成片长度截取；画面更长时，声音结束后补静音。

可以取消“只剪画轨”，让各片段声音随画面一起移动。
再勾选“分离音画轨”，可为每个片段独立指定音频范围。
此时音频入点、出点秒数以全部原素材按加入顺序拼接后的累计时间计算。
取消独立音频范围会重新对齐片段画面，可用撤销恢复。
原声连续模式的静音和音量是整条原声的设置；其他模式作用于当前片段。
导出音量最高 200%，连续预览音量最高 100%。

不同视频尺寸与帧率
• 多视频工程以第一个加入素材的显示画幅作为输出画幅。
• 其他尺寸或横竖屏视频按比例适配，空白处补黑边，不拉伸画面。
• 可混合常见恒定帧率、变帧率视频，按实际帧时间拼接。
• 为兼容 H.264，输出宽高会使用偶数尺寸。
• 单个源视频工程保持原有画幅处理方式。

导出
右上角“导出”可选择：
1. 成片 MP4：画面 + 声音。
2. 仅画面 MP4：不包含音轨。
3. 仅音轨：M4A，或无损 WAV。
4. 音画分离：分别生成 _画面.mp4 和 _音轨.m4a。

视频 H.264 / CRF 18，音频 AAC 192 kbps 或 WAV PCM / 48 kHz 双声道。
精确裁剪会重新编码。输出保存为新文件，不能覆盖任一源视频。
分离导出遇到已有同名文件会自动加序号。
取消时清理未完成的临时输出，已完成的分离文件会保留。

工程文件
工程保存为 .framecut，包含全部素材路径、片段顺序和声音拼接设置。
不嵌入原视频，重新打开时需要保留所有素材。
素材移动后会提示重新关联；素材大小或帧数变化时会拒绝套用旧裁剪位置。
支持读取 1.0 / 1.1 单视频工程；1.2 保存后的工程请使用 1.2 或更高版本打开。
支持最多 200 个素材、200 个画面片段、最近 100 步撤销。
导入失败或取消时，现有工程保持完整；添加视频本身也可以撤销、重做。

连续播放与兼容预览
常见 MP4 可直接连续播放；不兼容的素材可生成本地兼容预览。
兼容预览保存在程序旁的 .cache，正常关闭时清理。
逐帧查看和最终导出始终读取原视频。
首次导入需要建立帧索引，长视频耗时更久，可取消。

快捷键
空格                 播放 / 暂停
← / →                后退 / 前进 1 帧
Shift + ← / →        后退 / 前进 10 帧
I / O                设为入点 / 出点
S                    分割画轨
Home / End           当前片段首帧 / 尾帧
Ctrl + O             新建工程并打开视频
Ctrl + Shift + O     添加视频到当前工程（可多选）
Ctrl + S             保存工程
Ctrl + Z / Ctrl + Y  撤销 / 重做

当前范围
提供多素材拼接、精确片段剪辑和音画轨处理，不包含字幕、滤镜、转场、叠画或多层合成。
每个素材使用第一条非封面画面轨、第一条音轨，不保留其他附加轨、字幕和章节。
面向 SDR 素材，不提供 HDR 色彩管理或 HDR 母版导出。
所有处理均在本机进行。

第三方组件信息见 THIRD-PARTY.txt，源码单独提供。
