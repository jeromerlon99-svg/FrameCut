# 发布材料补齐记录

版本：1.2.1。日期：2026-11-27。

原先缺少旧 FFmpeg 大合集全部对应源码的问题，通过替换为由固定原始源码本地编译的组件解决。本记录只针对新的 1.2.1 二进制，不声称补齐了旧 1.2.0 大合集的所有材料。

## 已交付材料

- 应用 C# / XAML 源码、图标、示例、工程、编译与测试入口。
- FFmpeg 8.1.3、x264 固定提交、zlib 1.4 的完整原始源码包。
- 原始包来源、版本与 SHA-256；构建工具锁定记录。
- 实际使用的配置与编译脚本、配置结果、版本和运行文件散列。
- FFmpeg / x264 / zlib 及工具链运行库的许可通知。
- 完整绿色包中的源码副本，和可单独下载的同版源码包。
- GitHub 编译工作流和手动的完整构建 / 验证 / 打包工作流。

## 验证范围

新组件必须实际完成编译、核对导入表并通过媒体检查后才打包；测试记录随源码保存。已有的应用功能代码保留，应用版本与界面标识更新为 1.2.1。

Visual Studio / MSBuild 入口仍需 .NET Framework 4.8 Developer Pack；本项目基础应用编译已使用系统 C# 编译器验证。完整视频组件编译使用锁定的便携工具链，不要求把工具安装到系统。

## 发布使用

上传此源码目录，然后将 1.2.1 完整绿色 ZIP 与同版源码 ZIP 作为 Release 附件。运行包本身已含完整对应源码，不再只提供一个上游网址。具体命令见 [发布说明](PUBLISHING.md)。

本轮只准备本地文件，没有向你的 GitHub 上传、创建仓库或修改可见性。

本轮实际结果：新组件编译成功，运行导入表只有 Windows 系统 DLL；新组件下 123 项媒体与应用内部界面检查全部通过，见 verification-v1.2.1.txt。
